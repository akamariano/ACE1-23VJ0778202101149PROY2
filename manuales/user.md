# Manual de Usuario - Juego Programado en ASM

Este es un manual de usuario para el juego programado en ensamblador (ASM). A continuación, se proporciona una descripción de las funciones del juego y las instrucciones para jugar.

## Requisitos del Sistema

El juego programado en ASM no tiene requisitos especiales de hardware. Se puede ejecutar en cualquier sistema compatible con el ensamblador y el entorno de ejecución adecuados.

## Iniciar el Juego

Para iniciar el juego, sigue estos pasos:

1. Selecciona "Iniciar Juego" en el menú principal.
2. Elige el nivel que deseas jugar.
3. Utiliza las teclas de flecha (arriba, abajo, izquierda, derecha) para controlar al jugador en el juego.
4. Supera los desafíos y alcanza el objetivo del nivel para ganar.

## Cargar Nivel Personalizado

Si deseas cargar un nivel personalizado, sigue estos pasos:

1. Selecciona "Cargar Nivel" en el menú principal.
2. Se te pedirá que ingreses el nombre del archivo del nivel.
3. Escribe el nombre del archivo y presiona Enter.
4. El juego cargará el nivel personalizado y podrás comenzar a jugar.

## Configuración

El juego no tiene opciones de configuración disponibles en la versión actual.

## Puntajes Altos

El juego no registra puntajes altos en la versión actual.

## Salir del Juego

Si deseas salir del juego en cualquier momento, sigue estos pasos:

1. Selecciona "Salir" en el menú principal.
2. El juego se cerrará y volverás al sistema operativo.

## Controles del Juego

- Flechas (Arriba, Abajo, Izquierda, Derecha): Mover al jugador en el juego.

## Notas Adicionales

- El juego está diseñado para ser ejecutado en modo de pantalla completa.
- Algunas funciones adicionales pueden estar disponibles a través de combinaciones de teclas específicas no documentadas en este manual.
